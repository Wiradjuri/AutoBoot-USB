AutoBoot USB - UNSIGNED WINDOWS x64 PREVIEW - TESTING ONLY

No Python or development tools are required. Windows 10/11 x64 only.
Extract ALL files into a writable folder on your internal disk. Double-click
AutoBootUSB.exe. Keep _internal and all other files together. Do not run from
inside the ZIP or from the USB you intend to erase. Downloads are saved in
Images beside the executable; allow space for ISOs and temporary Windows files.

Launch normally. The existing UAC prompts request administrator approval for
USB writing (or read-only discovery when required). Check the target model,
capacity, serial and disk number in both erase confirmations. Creating media
erases the selected USB. Keep it connected until verification has finished.

This build is unsigned; Windows may show an Unknown Publisher/SmartScreen
warning. Verify its origin and ZIP SHA-256. Do not disable antivirus, UAC or
SmartScreen globally. If organisational policy blocks it, contact your admin.

Software checks do not establish physical USB or firmware boot compatibility.
Physical USB acceptance, firmware boot tests and code signing remain outstanding.
Use only disposable test media with backups. This is not a production release.

Portable refers to the application folder. Logs/preferences are stored in the
Windows user application-data folder. Remove the extracted folder to remove the
application; downloaded images in that folder will also be removed.
